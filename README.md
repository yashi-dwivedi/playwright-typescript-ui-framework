# Playwright TypeScript UI Automation Framework

A UI test automation framework built with **Playwright** and **TypeScript**, using the **Page Object Model (POM)** design pattern. Tests run against [Sauce Demo](https://www.saucedemo.com/), a public practice e-commerce site.

## What this project covers

- Login functionality: valid credentials and invalid credentials
- Page Object Model structure, separating locators/actions (`pages/`) from test logic (`tests/`)
- Cross-browser testing: Chromium, Firefox, and WebKit
- Assertions on page navigation and on-screen error messages
